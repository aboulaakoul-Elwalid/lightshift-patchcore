Anomaly detection under lighting shift

Vanilla PatchCore memory bank (WideResNet-50 features), a live lighting-shift generator, and a split-conformal threshold calibrated on clean normals at α = 0.1.

Drop an image here, or click to choose a file



The threshold comes from the conformal calibration on defect-free images only: k = ⌈(n+1)(1−α)⌉-th smallest calibration score. Under a lighting shift the bank matches the reference lighting, so shifted normal parts drift over threshold (false positives) — that is exactly the failure mode the project's B2 feature-stat alignment is designed to repair. Backend: FastAPI, CPU inference, banks exported from the reproduction-gate fits.
